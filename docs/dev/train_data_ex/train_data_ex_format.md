**train_data_ex**是本软件新引入的用于处理车辆信息的扩展数据，主要为了解决已有的 train_data 扩展性弱的问题。

基本语句
---
0. 本格式以**每行开头的第一个符号**作为指令类型的表达，且完全**不使用缩进**，**不允许语句内空格**。
1. “+”语句：用于指定一个新的车型，例如：
    ```text
    +CRH380A
    ```
    这时候所有的输入都会被引导到该车型。**在指定任意车型之前的数据**会作为**数据库自身的数据**。
2. “*”语句：用于标记**车型的数据**，有两种格式：
    1. 基本格式：
        ```text
        *speed=310
        ```
    2. 带**属性**的格式：
        ```text
        *(unvisible,int)speed=310
        ```
        属性：用于标记**数据的附加信息**，例如：
        1. invisible：用户不可见的。
        2. int：整型。
3. “#”语句：注释，忽略。
4. 无符号：**车型的信息**：
    ```text
    CRH380A是一款铁路动车组。
    ```
    **请尽量不要在信息的首字符使用符号**，这可能会对将来的扩展造成影响。

示例
---
```text
这是数据库信息
#这是注释
*database_version=1
+CRH380A
*(unvisible,int)speed=310
CRH380A是一款铁路动车组。
```
